# Contexto del proyecto

Estoy aprendiendo desarrollo frontend con este proyecto: la landing page de un producto inventado.
Vengo de Java (backend) y sé HTML básico. Es mi primer proyecto con React, TypeScript, Tailwind y librerías de animación.

El objetivo principal es APRENDER, no solo terminar la web. Prefiero entender menos cosas bien que muchas cosas mal.

## Stack
- React + Vite + TypeScript
- Tailwind CSS
- Motion (antes Framer Motion) para animaciones de interfaz
- GSAP + ScrollTrigger para animaciones ligadas al scroll (más adelante)

## Cómo quiero que trabajes conmigo

- Antes de escribir código, explícame brevemente el plan y espera mi confirmación en cambios no triviales.
- Haz cambios pequeños, de uno en uno. Nada de reescribir muchos archivos de golpe.
- Explica lo que haces y POR QUÉ, usando el nombre de cada técnica o concepto (p. ej. "flexbox", "stagger", "estado de React").
- Cuando haya una equivalencia útil con Java, menciónala (p. ej. package.json ≈ pom.xml).
- Comenta el código solo donde aporte algo para entenderlo, sin llenarlo de comentarios obvios.
- Si hay varias formas de hacer algo, dime cuáles y por qué eliges una.

## Modos de trabajo
Al pedirte una tarea indicaré el modo. Si no lo indico, pregúntame.

- **profesor**: NO escribas el código por mí. Explícame el concepto, dame pistas y revisa lo que yo escriba.
- **compañero**: yo lo intento primero; tú revisas, corriges y explicas cómo mejorarlo.
- **delegar**: hazlo tú, y al terminar resume qué has hecho y qué conceptos debería entender.

Regla general: la primera vez que aparece una técnica nueva, sugiere modo profesor o compañero.

## Aprendizaje
- Al terminar cada sección, hazme 2-3 preguntas cortas sobre lo que se ha hecho para comprobar que lo entiendo.
- Si ves que acepto cambios sin entenderlos, avísame.
- Si te pido que arregles un error, primero dime dónde mirarías y por qué, antes de darme la solución.

## Calidad
- Diseño responsive (móvil primero).
- Respetar `prefers-reduced-motion` en las animaciones.
- Mantener un estilo visual coherente con los tokens de diseño definidos (colores, tipografías, espaciados, curvas de animación).
